# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

Please report sensitive security issues directly to the maintainers:

- **Contact**: Zachary Shallbetter (`zach@snack.studio`)
- **PGP/Encrypted**: Available upon request.

Please do not open public GitHub issues for security vulnerabilities until a patched release is published.
We aim to acknowledge reports within 48 hours and provide remediation timelines promptly.
