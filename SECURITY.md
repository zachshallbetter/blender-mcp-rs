# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

Please report security issues privately through GitHub private vulnerability reporting:
<https://github.com/zachshallbetter/blender-mcp-rs/security/advisories/new>.

Please do not open public GitHub issues for security vulnerabilities until a patched release is published.

This is a solo-maintained project: responses are best-effort with no SLA.
