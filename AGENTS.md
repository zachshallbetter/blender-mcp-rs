## 1. Epistemic Integrity & Claim Taxonomy

Never conflate verification maturity:

$$\text{Documented} \neq \text{Implemented} \neq \text{Tested} \neq \text{Empirically Validated}$$

- **Documented**: A feature specified in markdown or architecture docs.
- **Implemented**: A feature with compiling Rust code in `crates/`.
- **Tested**: Verified via automated unit/integration tests with non-zero assertion counts.
- **Empirically Validated**: Verified against a live running Blender instance or game engine runtime with verified frame latency and physical response.

Always state the weaker claim when in doubt. Permanent retention of negative results is mandatory.

## 2. Hierarchy of Authority (`AUTHORITY.md`)

When documentation, code, generated artifacts, or AI outputs conflict, resolve in strict canonical order:

$$\text{Architecture \& Doctrine} \to \text{AUTHORITY.md} \to \text{Formal Protocols \& Schemas} \to \text{Substrate Code} \to \text{Generated Artifacts}$$

Code or AI model outputs never silently alter formal specifications. If code disagrees with spec, the code contains a defect until an authorized doctrinal change updates the spec.

## 4. Asset Craftsmanship Standard (The "Barrel Protocol")

All 3D tools and asset generators in this repository must enforce:
1. **Material Slot Budget**: $\le 2$ material slots per game asset.
2. **Explicit UV Mapping**: Direct quad UV loop mapping to game texture atlases. Never apply global cylindrical projections to non-cylindrical shapes.
3. **Physical 3D Relief**: Genuine physical geometry (plank grooves, chamfered rims, extruded hardware, 3D raised rivets with metallic highlights).
4. **Collision Hull Standards**: Lightweight convex hulls (`UCX_`), bounding boxes (`UBX_`), or capsules (`UCP_`) powered by Rapier3D / Parry.
5. **glTF Node Tree Preservation**: Modular child nodes parented under a root Empty node. Always export with `export_apply=False`.
